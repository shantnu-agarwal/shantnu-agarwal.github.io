# shantnu.in

The new shantnu.in is a dependency-free, responsive website built with vanilla HTML, CSS, and JavaScript.

## Structure

- `index.html` — homepage
- `style.css` — shared editorial design system and responsive layout
- `script.js` — accessible mobile navigation
- `about/`, `work/`, `notes/`, `life/`, `contact/` — static route foundations
- `docs/` — authoritative project specification
- `archive/legacy-2026-11-21/` — previous website retained for reference

No package manager or build step is required. Open `index.html` directly or serve the project directory with any static web server.
